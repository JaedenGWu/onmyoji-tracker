# 阴阳师手帖（Onmyoji List）第四版

《阴阳师手帖》第四版是一款专为 iPhone Safari、iPhone 主屏幕 PWA 及桌面浏览器设计的纯前端离线手帖应用，采用 Outlook 风格清爽蓝色界面，所有数据保存在浏览器本地（`localStorage`），支持北京时间任务周期自动重置与 JSON 完整备份恢复。

---

## 一、第四版新增与升级功能

1. **Outlook 风格蓝色视觉与外观主题系统**
   - 顶部采用 Outlook 风格主题色导航栏，统一卡片、按钮与交互强调色，完整适配 iPhone 刘海屏、灵动岛及底部安全区域。
   - **显示模式切换**：支持「浅色模式」「夜览模式（深色）」「跟随系统」，更改后立即生效并自动保存。
   - **主题色自定义**：内置 Outlook 蓝（默认）、经典蓝、紫色、绿色、洋红色、橙色及任意自定义颜色选择器，设置自动纳入 JSON 备份。
2. **统一 iOS 风格应用图标（浅色 + 深色双版本）**
   - 严格采用白底黑字（默认）与黑底白字（深色备用）两行居中排版（`onmyoji` / `リスト`），提供 `180×180`、`192×192`、`512×512` 完整尺寸 PNG 图标。
3. **资源记录系统升级（勾玉、符咒、体力、魂玉）**
   - 新增「魂玉」资源统计与历史记录。
   - 点击「保存本次资源记录」后，自动生成历史快照、更新当前资源总量，并**自动清空录入框与备注框**（不清空已保存的当前值与历史记录），方便连续记录。
   - **历史记录三大分组**：
     - **勾玉 + 符咒**：内置「历次记录」与「变化趋势」（勾玉、符咒独立折线图）两个子视图。
     - **体力**：独立历史记录列表，支持增减对比、备注、编辑与删除。
     - **魂玉**：独立历史记录列表，支持编辑与删除。
   - **全量历史编辑与删除**：所有资源历史记录均支持编辑数值、日期时间与备注，每条记录提供带二次确认的独立删除按钮。
4. **魂玉累充（永久置顶独立区域）**
   - 位于「魂玉」历史分组最上方永久置顶。
   - 支持增加（`+`）、减少（`-`）及手动校准当前累计数值，仅展示纯数字与正负号，不与游戏内魂玉数量混淆；支持查看、编辑、删除每次变化记录。
5. **第三版无缝数据迁移与 Schema v4 备份**
   - 首次打开第四版检测到旧版数据时，弹出选择窗口，支持「保留第三版数据（自动完整迁移）」或「不保留，开始全新使用（含二次确认）」。
   - JSON 导出升级为 `schemaVersion: 4`，导入时兼容第四版与第三版备份文件。

## 三、GitHub Pages 更新部署说明

1. **保留原有仓库与路径**：
   - 将本压缩包解压后的全部文件（`index.html`、`manifest.json`、`sw.js`、`README.md` 及 `icons/` 文件夹）上传并覆盖到你原有的 GitHub Pages 仓库根目录（或原项目子目录，例如 `/onmyoji-tracker/`）。
   - **切勿更改原有域名与访问路径**，以确保浏览器继续读取同一域名下的 `localStorage`（键值仍为 `onmyoji_tracker_v1`），从而无缝继承第三版数据。
2. **文件引用路径**：
   - 项目内所有静态资源均采用相对路径（`./manifest.json`、`./sw.js`、`./icons/...`），可直接在任意子路径下运行。
3. **更新生效机制**：
   - 第四版 `sw.js` 使用独立缓存名称 `onmyoji-tracker-v4-0-1` 并启用 `skipWaiting()` 与 HTML 网络优先策略，部署完成后刷新页面即可自动清理旧版缓存并加载第四版。

## 四、第三版数据迁移与全新初始化说明

- **保留第三版数据升级**：
  - 使用原 iPhone Safari 或主屏幕图标打开第四版时，若检测到本地存在第三版数据，会弹出「检测到《阴阳师手帖》旧版数据」提示框。
  - 点击**「保留第三版数据（自动完整迁移）」**，系统会自动保留全部账号、自定义任务、打卡状态、勾玉/符咒/体力历史快照与备注、日历备忘，并为魂玉、魂玉累充及外观设置初始化默认值。
- **不保留，开始全新使用**：
  - 若希望清空旧版测试数据重新开始，可点击**「不保留，开始全新使用」**，通过二次确认后将初始化干净的第四版默认数据。
- **通过 JSON 文件迁移**：
  - 也可在第四版「设置 → 数据备份与恢复」中直接导入第三版导出的 `.json` 备份文件，系统会自动识别并迁移。

## 五、iPhone 主屏幕图标添加与更新说明

1. **首次添加到主屏幕**：
   - 在 iPhone Safari 中打开部署后的 HTTPS 网址，点击底部「分享」按钮 → 选择「添加到主屏幕」→ 确认添加。
2. **从第三版更新主屏幕图标**：
   - 由于 iOS 系统机制限制，已固定在主屏幕上的旧版 Web App 图标不会在网页更新后自动替换桌面图标缓存。
   - **更新步骤**：先在第四版「设置」中导出一份 JSON 备份以防万一 → 长按删除主屏幕上的旧版图标 → 用 Safari 重新打开第四版网址并刷新 → 再次点击「分享 → 添加到主屏幕」，即可显示全新的白底黑字 `onmyoji / リスト` 图标。
   - 注：关于深浅色图标切换，iOS Safari 固定主屏幕图标不支持随系统深色模式动态替换已生成的桌面图标，因此默认提供白底黑字版本，同时在网页 `<head>` 与 `manifest.json` 中配置了黑底白字深色图标供支持的浏览器使用。
