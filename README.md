# 阴阳师手帖（第三版）

## 功能
- 多账号任务打卡：日常、周常、月常
- 全部账号进度总览
- 自定义任务、账号增删改名
- 勾玉、符咒、体力分账号统计
- 资源历史快照：勾玉/符咒折线图、资源增减对比
- 编辑资源历史记录的日期与时间，并为每条快照添加备注
- Outlook 风格月历：周日为每周第一天，点击日期即可添加/编辑当天备注
- 本地自动保存、JSON 导出/导入（包含资源历史和日历备注）
- 按北京时间切换日/周/月任务周期

## 在 iPhone 上使用
1. 将整个文件夹部署到支持 HTTPS 的静态网站托管服务（例如 GitHub Pages、Cloudflare Pages）。
2. 用 iPhone Safari 打开部署后的 `index.html`。
3. 点 Safari「分享」→「添加到主屏幕」。
4. 从主屏幕图标打开，即可作为独立网页应用使用。

注意：直接打开本地 HTML 可以预览交互，但 iOS 主屏幕安装和离线缓存需要 HTTPS 网站环境。
数据保存在当前浏览器本地。更换设备或清理 Safari 网站数据前，请在「管理」中导出备份。
